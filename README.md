# Vira Games Segmentation

Clean, interview-friendly project scaffold for a user segmentation test task focused on a mobile gaming portfolio.

## Structure

- `data/raw/`: reference to the original source dataset. Raw files are not duplicated or modified.
- `data/processed/`: future cleaned and feature-ready datasets created during analysis.
- `notebooks/`: Jupyter notebooks for exploratory work and the final reproducible analysis flow.
- `src/`: reusable Python code for data loading, feature creation, analysis utilities, and modeling.
- `outputs/figures/`: generated charts and visual assets exported from notebooks or scripts.
- `reports/`: short written summaries, notes, and supporting documents.
- `deliverables/`: final submission-ready artifacts.
- `requirements.txt`: Python dependencies required to run the notebook end-to-end.

## Notes

- The original assignment PDF remains in the repository root for reference.
- `data/raw/ds_test_task_dataset` is a symbolic link to the existing dataset folder in the project root.
- The notebook scaffold was created with reproducibility in mind and is intended to run top-to-bottom once analysis is implemented.
